# 车道与路径检测
## 项目简介
本项目基于 Python 与 OpenCV 实现自动驾驶场景下的车道线识别与路径规划功能，为后续在 Carla 仿真器中的应用提供基础的视觉感知算法支持。

## 开发环境
* **操作系统：** macOS / Windows 10/11
* **Python 版本：** Python 3.8+
* **依赖库：** OpenCV, NumPy

## 功能规划
### 1. 图像预处理模块
* **灰度化处理：** 将彩色图像转换为灰度图，降低计算复杂度
* **高斯模糊去噪：** 平滑图像，减少噪声干扰
* **Canny 边缘检测：** 提取图像中的边缘特征，为车道线识别做准备

### 2. 车道线检测模块
* **ROI 区域提取：** 截取图像中车道所在的有效区域，减少无关背景干扰
* **霍夫直线检测：** 识别图像中的直线，筛选出左右车道线
* **车道线拟合与分离：** 区分左右车道线并进行线性拟合

### 3. 路径规划模块
* **车道中心线计算：** 根据左右车道线计算车辆行驶的中心路径点
* **行驶路径可视化：** 在图像中标注中心路径点，直观展示规划结果
