# 城市公交班距控制与串车抑制优化

本项目实现了一个面向城市公交走廊的班距控制与串车抑制演示模块。公交线路在运行中容易受到局部延误影响，一辆车晚点后会遇到更多乘客、停站时间变长，后车又会追上前车，形成“公交串车”现象。串车会导致乘客等待不均衡、车辆满载不均和服务可靠性下降。本项目在无控制基线策略基础上，实现自适应站点等候控制，通过短时控车让公交班距重新接近目标间隔。

## 功能内容

- 构建包含 10 个站点、8 辆公交车的城市走廊运行场景。
- 设置不同站点的乘客到达率，模拟站点需求不均衡。
- 注入单车局部延误，用于触发后续公交串车风险。
- 实现无控制 `no_control` 基线策略。
- 实现自适应等候 `adaptive_holding` 优化策略，根据当前班距、下游追车风险和车厢拥挤度决定控车时间。
- 统计平均班距、班距标准差、班距变异系数、串车次数、乘客平均等待时间、总控车时间和服务可靠性评分。
- 生成公交时空图、班距热力图、站点乘客等待成本图和指标对比图。
- 输出 `headway_by_stop.csv` 和 `metrics.json`，方便复现实验和写提交说明。

## 运行方法

在本目录执行：

```bash
python main.py
```

也可以指定输出目录：

```bash
python main.py --output assets
```

运行后会生成：

- `time_space_diagram.png`：无控制与自适应等候策略下的公交时空运行图。
- `headway_heatmap.png`：优化策略下各车对、各站点的班距热力图。
- `passenger_wait_by_stop.png`：各站点乘客等待成本对比。
- `metric_comparison.png`：班距标准差、串车次数、平均等待和可靠性指标对比。
- `headway_by_stop.csv`：每一对相邻公交在各站点的班距数据。
- `metrics.json`：核心指标和优化百分比。

## 项目意义

该模块展示了公共交通智能调度中的典型问题：目标不是让每辆车都尽快跑完，而是让整条线路保持稳定服务。自适应站点等候会牺牲少量车辆运行时间，但可以降低班距波动，减少串车，并提升乘客感受到的服务可靠性。这类方法可以继续扩展到实时客流预测、公交专用道控制、多线路换乘协同和强化学习控车策略。

## 测试

```bash
python -m pytest tests
```

测试内容包括：

- 自适应等候策略是否降低班距标准差并减少串车。
- 每辆公交的站点发车时间是否保持单调递增。
- 主程序是否能生成指标文件和全部可视化图片。
