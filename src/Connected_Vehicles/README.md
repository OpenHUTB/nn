connected_vehicles
This Repository is part of a larger Project within the class "Interaktionskonzept" at the HSHL. [link to project-base]
本仓库为德国HSHL大学《Interaktionskonzept（交互概念设计）》课程综合大项目的子模块。[项目总库链接]
The goal is to simulate a Smart City, with multiple smaller actors and a central server.
项目目标是仿真搭建一座smart_city（智慧城市），包含多个小型功能单元（actors）和一台central_server（中央服务器）。
In this part, my task is to simulate a system that monitors the drivers in the city.
本模块中，我的任务是仿真搭建一套city_driver_monitoring_system（城市驾驶员监测系统）。
The system will monitor the drivers vitals and the crash detection of the car and release emergency messages in case a potential danger is detected.
该system（系统）将实时监测driver_vitals（驾驶员生命体征）和car_crash_detection（车辆碰撞检测），若检测到潜在危险，将发送emergency_messages（紧急信息）。
For this, I will be using the CARLA-Software to simulate multiple cars driving around.
为此，我将使用carla_software（CARLA仿真软件），仿真实现多车辆行驶场景。
