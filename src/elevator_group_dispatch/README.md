# 智能电梯群控调度与乘客等待时间优化

本项目实现了一个面向办公楼宇的电梯群控调度优化模块。传统电梯调度常采用“最近电梯响应”策略，能够快速找到一台看似最近的电梯，但在早高峰、午间跨楼层移动和晚高峰下行需求混合出现时，容易造成电梯空驶增加、部分乘客等待时间过长以及轿厢任务分配不均。本项目在最近电梯基线策略基础上，实现目的层感知的电梯群控调度策略，用于降低平均等待时间、90 分位等待时间和能耗指标。

## 功能内容

- 构建 16 层办公楼、4 台电梯、98 个乘客请求的群控调度场景。
- 模拟早高峰上行、午间跨楼层移动和晚高峰下行三类需求。
- 实现最近电梯 `nearest_car` 基线策略。
- 实现目的层感知 `destination_aware` 优化策略，综合考虑等待时间、运行方向、空驶距离和电梯负载均衡。
- 统计平均等待时间、90 分位等待时间、最大等待时间、平均乘梯时间、空驶楼层数、总运行楼层数和能耗指标。
- 生成等待时间分布图、电梯服务时序图、楼层需求热力图和指标对比图。
- 输出 `dispatch_assignments.csv` 和 `metrics.json`，方便复现实验和写提交说明。

## 运行方法

在本目录执行：

```bash
python main.py
```

也可以指定输出目录：

```bash
python main.py --output assets
```

运行后会生成：

- `wait_time_distribution.png`：最近电梯策略和目的层感知策略的等待时间分布对比。
- `elevator_timeline.png`：优化策略下每台电梯的服务时序和楼层移动轨迹。
- `floor_demand_heatmap.png`：不同时间段、不同起点楼层的乘客需求热力图。
- `metric_comparison.png`：平均等待、90 分位等待、长等待次数和能耗指标对比。
- `dispatch_assignments.csv`：每个乘客请求在两种策略下的分配电梯、接送时间和等待时间。
- `metrics.json`：核心指标和优化百分比。

## 项目意义

该模块展示了群体智能调度在楼宇交通系统中的应用。电梯群控与车辆调度、机器人调度有相似之处，核心都是在有限资源下分配任务，减少等待、空驶和拥堵。目的层感知策略不仅关注“哪台电梯最近”，还考虑乘客的目标楼层和系统整体负载，从而让电梯组运行更平衡。

该项目可以继续扩展到目的层预约输入、分区运行、VIP 优先级、拥挤度约束、能耗回收和强化学习电梯调度策略。

## 测试

```bash
python -m pytest tests
```

测试内容包括：

- 目的层感知策略是否降低平均等待时间和 90 分位等待时间。
- 每个乘客请求是否被服务且只服务一次。
- 主程序是否能生成指标文件和全部可视化图片。
