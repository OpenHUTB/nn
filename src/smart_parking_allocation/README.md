# 智慧停车场车位分配与拥堵均衡优化

本项目实现了一个面向智慧停车场的车位分配与拥堵均衡优化模块。传统停车场常按照“离入口最近”或“先看到先停”的方式分配车位，这会导致部分区域过度拥挤、车辆绕行距离增加，充电车位和无障碍车位也可能没有被合理保留。本项目在最近车位基线策略基础上，实现兼顾步行距离、区域负载、入口行驶距离、出口距离和特殊车位需求的均衡分配策略。

## 功能内容

- 构建包含 A、B、C、D 四个区域的停车场布局，共 84 个车位。
- 设置普通车位、充电车位和无障碍车位三类资源。
- 模拟一天内早高峰、午间和晚高峰共 84 辆车的停车需求。
- 实现最近车位 `nearest_spot` 基线策略。
- 实现负载均衡 `balanced_allocation` 优化策略，综合考虑区域拥挤度、步行距离、入口行驶距离、出口距离和特殊需求。
- 统计服务车辆数、拒绝车辆数、平均步行距离、90 分位步行距离、区域峰值占用率、区域不均衡指数和场内行驶距离。
- 生成停车场布局分配图、区域占用曲线、步行距离分布图和指标对比图。
- 输出 `parking_assignments.csv` 和 `metrics.json`，方便复现实验和写提交说明。

## 运行方法

在本目录执行：

```bash
python main.py
```

也可以指定输出目录：

```bash
python main.py --output assets
```

运行后会生成：

- `parking_layout_allocation.png`：停车场布局、入口出口和优化策略下的分配车位。
- `zone_occupancy_curve.png`：全天总占用和各区域占用变化。
- `walking_distance_distribution.png`：最近车位和均衡分配策略的步行距离分布。
- `metric_comparison.png`：平均步行、90 分位步行、区域不均衡和场内交通距离对比。
- `parking_assignments.csv`：每辆车在两种策略下的车位、区域和步行距离。
- `metrics.json`：核心指标和优化百分比。

## 项目意义

该模块展示了智慧停车系统中的资源调度思想。车位分配不仅是找到一个空车位，还要让充电车、无障碍车辆、短停车辆和普通车辆在有限空间中更合理地分布。均衡策略可以降低局部拥堵，减少找车位造成的场内冲突，并为后续路径引导、预约停车和动态定价提供基础。

该项目可以继续扩展到车位预约、车牌识别、动态收费、车流仿真、停车机器人泊车和多入口停车场协同调度。

## 测试

```bash
python -m pytest tests
```

测试内容包括：

- 均衡分配策略是否降低区域不均衡指数。
- 充电和无障碍特殊请求是否在可行范围内被服务。
- 主程序是否能生成指标文件和全部可视化图片。
