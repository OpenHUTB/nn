# 电动汽车充电站排队调度与负载削峰优化

本项目实现了一个面向城市电动汽车充电站的排队调度与负载削峰演示模块。随着电动汽车数量增加，充电站在早晚高峰容易出现车辆排队、充电桩拥堵和电网负载尖峰。如果所有车辆按照先到先充的方式立即开始充电，可能会叠加建筑基础负载，造成超过电网功率限制的峰值。本项目在先到先充基线策略基础上，引入考虑车辆截止时间、优先级、太阳能出力和电网限制的负载感知调度策略。

## 功能内容

- 构建 24 小时充电站场景，包含 30 辆车的到达时间、充电需求和离站截止时间。
- 设置 6 个 22 kW 充电桩，模拟充电站在早高峰、午间和晚高峰的到站需求。
- 构建建筑基础负载曲线和白天太阳能发电曲线。
- 实现先到先充 FCFS 基线策略。
- 实现负载感知调度策略，综合考虑等待时间、截止时间、电网超限、太阳能匹配和充电桩占用。
- 统计平均等待时间、完成车辆数、截止时间违约数、电网峰值、超限分钟数、太阳能利用率和负载方差。
- 生成负载曲线对比图、充电桩占用图、等待时间分布图和指标对比图。
- 输出 `vehicle_schedule.csv` 和 `metrics.json`，方便复现实验和写提交说明。

## 运行方法

在本目录执行：

```bash
python main.py
```

也可以指定输出目录：

```bash
python main.py --output assets
```

运行后会生成：

- `load_profile_comparison.png`：FCFS 与负载感知调度的电网净负载曲线。
- `charger_occupancy.png`：两种策略下的充电桩占用变化。
- `waiting_time_distribution.png`：车辆等待时间分布对比。
- `metric_comparison.png`：平均等待、峰值负载、超限分钟和负载方差对比。
- `vehicle_schedule.csv`：每辆车在两种策略下的开始、结束和等待时间。
- `metrics.json`：核心指标和优化百分比。

## 项目意义

该模块体现了智能交通和能源系统协同优化的思路。充电站不只是车辆补能设备，也是电网负载的一部分。通过在车辆可接受的停车窗口内调整充电开始时间，系统可以减少峰值负载和电网超限时间，同时尽量利用太阳能出力。这类方法可以继续扩展到动态电价、V2G 反向放电、公交车队补能、园区微电网和多站点协同调度。

## 测试

```bash
python -m pytest tests
```

测试内容包括：

- 负载感知调度是否降低电网峰值负载。
- 调度结果是否始终不超过充电桩数量和站内功率上限。
- 主程序是否能生成指标文件和可视化图片。
