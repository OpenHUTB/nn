    配置说明

    速度配置 SPEED_CONFIG

    控制关节运动和夹爪动作的时间参数。通过命令行第 2 个参数或函数参数 speed 选择。

    模式 关节运动时长 夹爪动作时长 暂停间隔 适用场景
    slow 3.0s 1.5s 0.02s 调试观察、精度要求高
    medium 2.0s 1.0s 0.001s 日常使用（默认）
    fast 1.0s 0.5s 0.0005s 批量测试、追求效率

    参数说明

    参数 含义 影响
    joint 单关节移动的目标时间 越小越快，精度可能下降
    grip 夹爪闭合/张开的目标时间 越小越快
    pause 仿真步进间隔 影响渲染帧率和 CPU 占用

    夹爪力度配置 GRIP_CONFIG

    控制夹爪闭合时施加的力度（速度幅值）。通过命令行第 4 个参数或函数参数 grip_force 选择。

    力度 闭合速度值 适用场景
    light 0.15 易碎物体、轻质小球
    medium 0.25 常规物体（默认）
    heavy 0.35 重物、需要强力夹持

    注意

    力度越大夹爪闭合越快，但过大的力度可能导致物体被弹飞。建议根据目标物体特性选择合适的力度。

    目标随机位置

    target_auto_reset() 函数在以下范围内随机生成目标位置：

    轴 范围 说明
    X [0.5, 1.2] 工作平台前方区域
    Y [0.3, 1.2] 工作平台侧面区域
    Z 0.0（固定） 平台表面高度

    如需修改随机范围，编辑 main.py 中 target_auto_reset() 函数内的 x_range 和 y_range 变量：

    x_range = (0.5, 1.2)  # X 范围
y_range = (0.3, 1.2)  # Y 范围

    MuJoCo 物理参数

    机械臂模型的核心物理参数定义在 robot_arm.xml 中：

    参数 值 说明
    timestep 0.005s 物理仿真步长
    gravity (0, 0, -9.81) 重力加速度
    关节阻尼 0.03 防止振荡
    夹爪阻尼 0.02 软接触控制

    执行器 PID 参数

    执行器 kp kv 说明
    关节位置控制 1100 100 高精度位置跟随
    夹爪速度控制 - 40 软接触速度控制

    重试机制

    grab_and_place() 函数内置重试机制：

    • 默认最大重试次数：2 次（可通过 retry_max 参数调整）
    • 连续失败警告：连续失败 3 次后，程序暂停并提示用户检查
    • 失败处理：每次失败后自动调用 robot_auto_reset() 复位

    日志配置

    运行日志自动追加到 grasp_log.txt 文件中，每条记录包含：

    [日期时间] 抓取N次, 成功M次, 成功率X%, 速度:xxx, 力度:xxx, 总耗时:X秒

    日志编码为 GBK，确保在 Windows 中文环境下正常显示。
