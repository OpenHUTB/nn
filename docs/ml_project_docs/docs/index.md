# 基于CARLA的自动驾驶可视化监控系统

[![Python 3.7+](https://img.shields.io/badge/python-3.7+-blue.svg)](https://www.python.org/downloads/)
[![CARLA 0.9.14+](https://img.shields.io/badge/CARLA-0.9.14+-orange.svg)](https://carla.org/)

本项目基于 [CARLA](https://carla.org/) 模拟器构建，为自动驾驶车辆提供一站式实时监控与可视化 HUD（Head-Up Display）解决方案。

## 核心功能

### 实时视觉监控

- 前置 RGB 摄像头，640×480 分辨率，安装于车辆前方 2.5m、高度 1.5m 处
- 基于 CARLA 同步模式（`fixed_delta_seconds = 0.05`），帧率稳定在 20 FPS
- 摄像头数据通过 `listen(callback)` 异步回调，经 NumPy 解码后由 OpenCV 渲染

### 车辆状态监控

- 实时计算并显示行驶速度（由 `get_velocity()` 三轴分量合成，转换为 km/h）
- 可调节超速阈值（默认 60 km/h，最低 10 km/h），超速时速度数字变红
- 速度警告可独立开关（`W/w` 键）

### 多视角自由切换

支持 5 种视角模式，大小写不敏感：

| 按键 | 视角模式 | 实现方式 |
|------|----------|----------|
| `T/t` | 俯视视角 | 车辆上方 50m，俯角 -90° |
| `F/f` | 跟随视角 | 后方 5m、上方 3m，俯角 -15° |
| `C/c` | 追逐视角 | 后方 5m、上方 2m，俯角 -10° |
| `S/s` | 侧视视角 | 侧方 5m、上方 3m，偏航 +90° |
| `X/x` | 近距离视角 | 后方 5m、上方 4m，俯角 -25° |

所有视角通过 `world.get_spectator().set_transform()` 实时更新，跟随车辆位置与朝向。

### 智能导航系统

- 从地图生成点中随机选取距离当前位置 > 50m 的目的地
- HUD 面板显示导航开关状态
- 按 `N/n` 键重新随机选择导航目的地

### 环境模拟系统

5 种天气模式，每种天气有独立的物理参数配置：

| 天气 | 云量 | 降水 | 雾密度 |
|------|------|------|--------|
| 晴天 Clear | 0 | 0 | 0 |
| 多云 Cloudy | 80 | 0 | 20 |
| 雨天 Rain | 100 | 80 | 30 |
| 雾天 Fog | 90 | 20 | 60 |
| 雪天 Snow | 100 | 100 | 40 |

- 24 小时时间系统：太阳高度角 = `(hour - 6) × 15°`
- `V/v` 循环切换天气，`U/u` 每次增加 3 小时

### 自动泊车功能

6 阶段侧方位停车状态机：

| 阶段 | 操作 | 触发条件 |
|------|------|----------|
| 0 | 全力制动 | 启动泊车 |
| 1 | 油门 0.4 + 左满舵 | 阶段 0 完成 |
| 2 | 全力制动 | 车速 > 2 m/s |
| 3 | 油门 0.4 + 右满舵 + 倒档 | 阶段 2 完成 |
| 4 | 油门 0.3 + 倒档 | 阶段 3 完成 |
| 5 | 制动停车，恢复自动驾驶 | 阶段 4 完成 |

按 `P/p` 键启动，泊车期间禁用自动驾驶，完成后自动恢复。

### 多车型切换

支持 5 种车型（切换后保持当前位置）：

- `vehicle.tesla.model3` — Tesla Model 3
- `vehicle.mercedes.coupe` — Mercedes Coupe
- `vehicle.audi.a2` — Audi A2
- `vehicle.bmw.isetta` — BMW Isetta
- `vehicle.ford.crown` — Ford Crown

按 `K/k` 键顺序切换。

### 行驶轨迹回放

- 实时记录车辆位置至轨迹点队列，最大容量 200 个点
- 超过上限时移除最旧的点（FIFO 队列）
- 世界坐标 → 图像坐标转换：`img_x = 320 + (world_x - current_x) × 5`
- 渐变色绘制：蓝色（最新）→ 绿色（中间）→ 红色（最旧）
- 仅在画面范围内（0-640, 0-480）绘制线段
- 按 `R/r` 键重置轨迹

## 快速开始

### 环境准备

- CARLA Simulator 0.9.14+
- Python 3.7+
- 依赖安装：

```bash
pip install opencv-python numpy
```

### 运行步骤

1. 启动 CARLA 模拟器（需先安装 CARLA）：

```bash
CarlaUE4.exe
```

2. 运行主程序：

```bash
python main.py
```

3. 程序启动后自动在随机位置生成 Tesla Model 3 并开启自动驾驶，HUD 窗口显示实时画面。

## 常见问题

**画面卡顿**

检查 CARLA 模拟器资源占用，可尝试降低摄像头分辨率（修改 `image_size_x` / `image_size_y` 属性），或增大 `fixed_delta_seconds` 降低帧率。

**视角切换无响应**

确认键盘焦点在 OpenCV 窗口中（窗口标题 "HUD"），按键判断使用 `cv2.waitKey()`，大小写均支持。

**自动泊车失败**

确保车辆已完全停止（泊车阶段 0 先执行制动），且泊车区域周围无障碍物阻挡。

**导航不生成**

确认 CARLA 地图已完全加载，且车辆当前位置周围存在距离 > 50m 的生成点。如所有生成点均 ≤ 50m，不会生成导航。

**连接 CARLA 超时**

确认 CARLA 模拟器已在 `localhost:2000` 运行。程序连接超时设置为 20 秒，超时未连接将抛出异常。
