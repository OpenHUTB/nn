# 机械臂抓取模块

基于 **MuJoCo 3.4.0** 物理仿真引擎的 **3 自由度机械臂精准取放系统**，支持自动复位、抓取计时、速度调节和力度控制等功能。

## 机械臂结构

机械臂由三个关节组成：

| 关节 | 类型 | 运动轴 | 范围 |
|------|------|--------|------|
| 关节1（基座旋转） | Hinge | Z 轴 | [-3.14, 3.14] rad |
| 关节2（大臂俯仰） | Hinge | Y 轴 | [-1.5, 1.5] rad |
| 关节3（小臂伸缩） | Slide | X 轴 | [0, 0.4] m |

末端配备**平行夹爪**，用于抓取蓝色球体目标并放置到绿色目标区域。

## 功能特性

- **自动复位**：每次抓取完成后机械臂和目标自动复位
- **抓取计时**：记录每次抓取耗时和总耗时
- **速度调节**：支持 slow / medium / fast 三种速度模式
- **力度控制**：支持 light / medium / heavy 三种夹爪力度
- **重试机制**：抓取失败自动重试，连续失败给出警告
- **成功率统计**：统计并输出总成功率
- **日志记录**：自动将运行结果保存到 `grasp_log.txt`
