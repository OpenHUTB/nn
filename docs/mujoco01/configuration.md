# 配置说明

本文档详细介绍 `mujoco01` 仿真模块中所有可配置参数的含义、默认值及调整建议。

## PD 控制参数

PD 控制器作用于 15 个稳定关节，计算公式为：

\[
\tau = k_p \cdot (q_{des} - q_{cur}) - k_d \cdot \dot{q}
\]

| 参数 | 默认值 | 说明 | 调整建议 |
|:---|:---:|:---|:---|
| `kp` | 35.0 | 比例增益，决定位置误差的响应强度 | 增大 → 更"硬"的姿态保持，但可能振荡；减小 → 更柔和但跟踪精度下降 |
| `kd` | 8.0 | 微分增益，抑制振荡的阻尼 | 增大 → 更平稳但响应变慢；减小 → 响应快但可能抖动 |

### 典型调参组合

| 场景 | kp | kd | 效果 |
|:---|:---:|:---:|:---|
| 严格保持姿态 | 50.0 | 10.0 | 刚度高，机器人不易偏离 keyframe |
| 柔和控制 | 20.0 | 5.0 | 允许一定偏移，运动更自然 |
| 高阻尼 | 35.0 | 15.0 | 动作平滑，但抬手响应会稍慢 |

## 抬手动作参数

右肘关节按固定周期执行分段线性力矩轨迹：

```
力矩
 ↑
 │     ┌──────┐
 │    ╱        ╲
 │   ╱          ╲
 │  ╱            ╲
 └─┴─────┴─────┴──→ 时间
   上升  保持  下降
   2s    2s    2s
```

| 参数 | 默认值 | 说明 |
|:---|:---:|:---|
| `elbow_lift_max` | 0.25 | 肘关节最大力矩（N·m），控制抬手幅度 |
| `cycle_period` | 6.0 | 完整抬手周期（秒），包含上升+保持+下降 |

### 周期分段

| 阶段 | 时间范围 | 力矩曲线 |
|:---|:---|:---|
| **上升** | 0 ~ 2s | 从 0 线性增长到 `elbow_lift_max` |
| **保持** | 2 ~ 4s | 恒定 `elbow_lift_max` |
| **下降** | 4 ~ 6s | 从 `elbow_lift_max` 线性降至 0 |

### 调整建议

- **加快抬手**：减小 `cycle_period`（如设为 3.0）
- **加大幅度**：增大 `elbow_lift_max`（如设为 0.5）
- **修改各阶段时长**：直接修改 `main.py` 中的分段逻辑

## 信号处理参数

| 参数 | 默认值 | 说明 | 调整建议 |
|:---|:---:|:---|:---|
| `smooth_alpha` | 0.06 | EMA 平滑系数，控制信号低通滤波强度 | 值越小 → 越平滑但响应延迟越大；值越大 → 响应快但可能抖动 |
| `max_torque` | 1.0 | 力矩限幅（N·m），所有执行器的输出上限 | 增大允许更强力矩输出，但可能造成仿真不稳定 |

## 扩展方向

### 修改初始姿态

编辑 `humanoid.xml` 中的 `<keyframe>` 部分，修改 `qpos` 值即可改变初始姿态：

```xml
<keyframe>
    <key name="home"
        qpos="0 0 0.3                    ← 根位置 (x, y, z)
              0.7071 0 0.7071 0          ← 根姿态四元数 (w, x, y, z)
              0 0 0                       ← 腹部关节
              ..."/>
</keyframe>
```

### 自定义模型

修改 `humanoid.xml` 可以调整：

- **物理属性**：质量、尺寸、摩擦系数
- **关节范围**：`range` 属性
- **执行器参数**：`gear`（齿轮比）、`ctrlrange`
- **重力**：`<option gravity="0 0 -9.0"/>`

### 增强控制策略

- 添加更多关节的周期性运动（如双腿交替抬起）
- 实现阻抗控制替代纯 PD 控制
- 添加外部力扰动测试鲁棒性

### 数据后处理

仿真结束后，可用 pandas/matplotlib 分析 `simulation_data.csv`：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("simulation_data.csv")
plt.plot(df["time"], df["qpos_18"])  # 右肘关节角度
plt.xlabel("Time (s)")
plt.ylabel("Elbow Angle (rad)")
plt.show()
```
