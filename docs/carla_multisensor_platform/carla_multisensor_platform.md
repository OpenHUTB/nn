# CARLA 多传感器自动驾驶仿真平台开发汇报文档
## 一、项目概述
本项目是基于CARLA 0.9.15版本模拟器构建的**多传感器融合自动驾驶仿真与数据采集平台**，面向自动驾驶算法研发、数据集构建等场景需求。平台集成RGB相机、激光雷达、深度相机、语义分割等多类传感器，支持手动/自动驾驶双模式切换，具备实时可视化、多维度数据同步记录、车道检测等核心能力，可输出标准化的自动驾驶训练数据集，操作便捷且数据格式规范。

## 三、问题修复记录
### 1. 初始运行报错修复
- **错误1**：`ModuleNotFoundError: No module named 'carla'`
  - 原因：CARLA Python API未正确加入Python路径，egg文件引用路径错误
  - 解决方案：通过glob匹配CARLA安装目录下的egg文件，自动添加至sys.path；同时支持pip安装carla备用方案

- **错误2**：`AttributeError: 'EgoVehicleController' object has no attribute 'controller'`
  - 原因：车辆控制器类未初始化核心控制属性，setup阶段赋值逻辑缺失
  - 解决方案：在EgoVehicleController类__init__中初始化`self.controller = None`，并在setup_ego_vehicle方法中完成carla.VehicleControl对象赋值

- **错误3**：`RuntimeError: Actor not found`（传感器/车辆销毁阶段）
  - 原因：仿真退出时actor已被销毁，重复调用destroy方法触发异常
  - 解决方案：在cleanup函数中增加try-except捕获RuntimeError，按类型过滤actor并安全销毁

- **错误4**：激光雷达数据解析异常导致程序卡顿
  - 原因：点云数据解析未做异常处理，无效数据触发数组越界
  - 解决方案：在lidar_callback中增加全局异常捕获，筛选有效点云数据（x>0、|y|<2）后再计算最近障碍物距离

### 2. 功能逻辑优化
- 修复自动驾驶模式下手动控制信号残留问题：切换自动驾驶时重置油门/转向/刹车参数
- 解决同步模式下world.tick()调用时机错误导致的仿真卡顿
- 优化传感器数据录制逻辑：按采样率（10Hz）控制数据写入，避免磁盘IO过载
- 完善EagleEyeMap绘制逻辑，解决车辆位置更新不及时导致的地图偏移问题

## 四、最终完整功能说明
### 1. 基础运行功能
- ✅ 自动连接CARLA模拟器，支持指定地图（默认Town10HD）、车辆类型（默认特斯拉Cybertruck）
- ✅ 多传感器灵活配置：支持RGB相机、深度相机、激光雷达、语义分割相机等启用/禁用
- ✅ 激光雷达实时检测：计算车辆前方2米范围内最近障碍物距离，为避障逻辑提供数据
- ✅ 程序退出自动清理：销毁所有车辆、行人、传感器actor，重置CARLA世界设置

### 2. 数据采集功能
- ✅ 多维度数据同步记录：
  - 图像数据：RGB相机帧（400×224 JPG格式）
  - 控制信号：转向、油门、刹车参数
  - 车辆状态：速度、位置、坐标变换、时间戳
- ✅ 录制控制：R键启停录制，S键查看录制状态，支持自定义输出目录（默认dataset）
- ✅ 标准化数据格式：按session分目录存储，包含images（图像）、metadata（帧元信息）、session_summary.json（会话汇总）

### 3. 驾驶控制功能
#### 手动驾驶模式（默认）
- 键盘操控：W/↑加速、S/↓刹车、A/←左转、D/→右转、空格手刹
- 障碍物感知：激光雷达检测前方障碍物距离，辅助手动驾驶避障
- 实时控制更新：每帧更新车辆控制信号，保证操控响应性

#### 自动驾驶模式（P键切换）
- 启用CARLA原生自动驾驶：车辆自动沿道路行驶
- 模式切换保护：切换时清空手动控制信号，避免控制冲突
- 随时切回手动：再次按下P键即可恢复手动驾驶

### 八、常见问题解决
1. 仿真启动超时
   - 现象：timeout waiting for simulator
   - 解决：确认 CARLA 服务器已启动，检查代码中 CarlaEnvironment 的 timeout 参数（默认 10s），确保端口为 2000（CARLA 默认端口）
2. 传感器画面不显示
   - 现象：Pygame 窗口无传感器画面
   - 解决：检查 sensors_dict 中对应传感器的 enabled 状态为 True，确认传感器位置参数（x/y/z）合理
3. 数据录制无文件生成
   - 现象：按 R 键无 dataset 目录生成
   - 解决：确认 DataRecorder 的 enable_recording 初始状态为 False（需 R 键开启），检查输出目录权限，确保采样率（10Hz）下有足够帧数据
4. 自动驾驶模式无响应
   - 现象：按 P 键后车辆未自动行驶
   - 解决：确认 CARLA traffic_manager 已初始化，检查 ego_vehicle.set_autopilot (autopilot_enabled) 调用逻辑，确保道路有可行驶路径（推荐使用 Town01/Town10HD 等带完整路网的地图）
## 项目总结
本项目基于 CARLA 0.9.15 仿真平台，搭建了一套集多传感器数据采集、车辆控制、实时可视化与数据集录制于一体的自动驾驶仿真系统。项目实现了相机、激光雷达等多种传感器的集成部署，完成手动驾驶与 CARLA 自动驾驶模式一键切换，并依托激光雷达实现前方障碍物检测功能。

系统支持自定义采样率的数据录制，可同步保存图像、车辆控制信号、行驶状态等信息，输出标准化数据集。开发过程中解决了环境对接、代码报错、逻辑冲突等多项问题，同时完善了程序异常捕获与仿真资源自动回收机制，保障系统稳定运行。

整体架构模块化、易扩展，不仅可用于自动驾驶算法调试、感知功能验证，也能快速构建训练数据集。后续可围绕多传感器融合、自动避障、车道检测、性能优化等方向继续迭代，进一步提升平台实用性与智能化水平。
